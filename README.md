# 🏷️ Consulta de CEP

Aplicação completa **React + Node.js** para consultar endereços a partir de um CEP brasileiro. Permite ao usuário inserir um CEP, verificar se é válido e visualizar os dados e o local no Google Maps.

---

## 🔎 Funcionalidades

- ✅ Busca de endereço via CEP usando `cep-promise`
- ✅ Exibição dos dados: rua, bairro, cidade, estado
- ✅ Visualização do local no mapa com Google Maps
- ✅ Botão para abrir diretamente no Google Maps
- ✅ Validação de CEP com mensagens claras de erro ou sucesso
- ✅ Modo claro/escuro com botão estilizado e interativo
- ✅ Layout responsivo para desktop e mobile

---

## 🛠️ Tecnologias Utilizadas

### Frontend
- React 18
- CSS responsivo
- Fetch API

### Backend
- Node.js + Express
- cep-promise
- cors

---

## 🚀 Como executar localmente

### Requisitos:
- Node.js 18+
- npm instalado

### 1. Clonar o repositório
```bash
git clone https://github.com/seu-usuario/cep-consultancy-api.git
cd cep-consultancy-api
````
### 2. Instalar e iniciar o backend
```bash
cd backend
npm install
npm start
````
### 3. Instalar e iniciar o frontend
Abra outro terminal:
```bash
cd frontend
npm install
npm start
````
